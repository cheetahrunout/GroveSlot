# GroveSlot

A Grove Street themed slot machine for the browser. You play with free tokens only: no real money, no purchases, no cash-out.

See [PLAN.md](PLAN.md) for the full design and milestones.

## Develop

```sh
npm install
npm run dev        # local dev server
npm test           # unit tests
npm run build      # type-check + production build into dist/
```
